Installation

Windows

  1. Extract the official NikaToolFlow customer package.
  2. Close Adobe Premiere Pro.
  3. Run installer/install-windows.bat.
  4. Keep the internet available on the first install while the optional YouTube runtime is prepared.
  5. Restart Premiere and open Window → Extensions → NikaToolFlow.

macOS

  1. Extract the official customer package and close Premiere.
  2. Run installer/install-macos.command. If required, allow execution in macOS security settings.
  3. Restart Premiere and open Window → Extensions → NikaToolFlow.

Only download the customer package from the official delivery link. The seller source package, signing private key, internal tests, and seller tools are never part of a legitimate customer download.

شرایط استفاده و لایسنس

با دانلود، نصب، فعال‌سازی یا استفاده از NikaToolFlow، مشتری شرایط نهایی نمایش‌داده‌شده هنگام پرداخت و همراه محصول را می‌پذیرد. در صورت اختلاف، متن نهایی پرداخت اولویت دارد.

مجوز استفاده

لایسنس خریداری‌شده به مشتری نام‌برده اجازه‌ای محدود، غیرانحصاری و غیرقابل‌انتقال برای نصب و استفاده از نسخه خریداری‌شده روی تعداد سیستم اعلام‌شده هنگام پرداخت می‌دهد. تنظیم پیش‌فرض محصول برای یک سیستم دارای مجوز است.

محدودیت‌ها

  • پکیج مشتری یا اطلاعات فعال‌سازی را بازفروش، منتشر، واگذار یا با دیگران به اشتراک نگذارید.
  • برای دورزدن لایسنس، حذف اطلاعات مالکیت یا استفاده غیرقانونی از محصول تلاش نکنید.
  • YouTube Grab را فقط برای محتوایی به‌کار ببرید که مالک آن هستید، اجازه استفاده دارید یا مجاز به دانلودش هستید.

رفتار نرم‌افزار

NikaToolFlow یک افزونه مستقل CEP برای Adobe Premiere Pro است. بعضی عملیات فرمان‌های Native پریمیر را اجرا می‌کنند؛ بنابراین عملکرد می‌تواند به بیلد دقیق پریمیر، سیستم‌عامل، پنل فعال، انتخاب و زبان رابط بستگی داشته باشد. ابزارهای آزمایشی QE اختیاری و به‌صورت پیش‌فرض پنهان هستند.

به‌روزرسانی و تغییرات

به‌روزرسانی‌های نگهداری نسخه CEP می‌توانند قابلیت‌ها، سازگاری، Installer یا Runtimeهای جانبی را تغییر دهند. نسخه احتمالی UXP یا مهاجرت بزرگ پلتفرم ممکن است شرایط جداگانه داشته باشد.

سلب مسئولیت

همیشه از پروژه نسخه پشتیبان بگیرید و ابزارهای جدید را ابتدا روی کپی پروژه آزمایش کنید. تا حد مجاز قانون، عملکرد بدون وقفه روی تمام سیستم‌ها، Codecها، شرایط شبکه یا نسخه‌های آینده پریمیر تضمین نمی‌شود. حقوق اجباری مصرف‌کننده محدود نمی‌شوند.

حریم خصوصی

این فروشگاه به‌صورت Static طراحی شده و در حالت پیش‌فرض به حساب کاربری نیاز ندارد. پس از اتصال پرداخت، ارائه‌دهنده درگاه ممکن است اطلاعات هویتی، پرداخت، مالیات، جلوگیری از تقلب و تراکنش را براساس سیاست حریم خصوصی خود پردازش کند.

فعال‌سازی محصول

نسخه فعلی یک Device ID برای صدور لایسنس امضاشده و وابسته به دستگاه نمایش می‌دهد. بررسی لایسنس برای کار آفلاین طراحی شده است. فروشنده باید فقط اطلاعات لازم برای تحویل، پشتیبانی، حسابداری، جلوگیری از تقلب و الزامات قانونی را نگه دارد.

YouTube Session

Session اختیاری YouTube به‌صورت پیش‌فرض خاموش است. Cookie مرورگر فقط پس از انتخاب صریح مرورگر یا فایل Cookie توسط کاربر، به‌صورت محلی خوانده می‌شود و NikaToolFlow برای ذخیره محتوای Cookie طراحی نشده است.

تماس و گزارش خطا

هنگام تماس با پشتیبانی، اطلاعاتی مانند ایمیل، Device ID، نسخه پریمیر، سیستم‌عامل، تصویر خطا و جزئیات تشخیصی ممکن است برای پاسخ و بهبود محصول استفاده شوند. مدیای پروژه، رمز عبور، Private Key یا داده محرمانه نامرتبط ارسال نکنید.

سیاست بازپرداخت

شرایط بازپرداخت محصول دیجیتال براساس متن نهایی هنگام پرداخت و قوانین قابل اعمال مصرف‌کننده تعیین می‌شود. پیش از خرید، سازگاری و نسخه آزمایشی موجود را بررسی کنید.

  • در صورت خراب‌بودن پکیج، مشکل فعال‌سازی یا کارنکردن یک ترکیب تضمین‌شده در جدول تست منتشرشده، سریع با پشتیبانی تماس بگیرید.
  • شماره سفارش، بیلد دقیق پریمیر، نسخه سیستم‌عامل و توضیح کوتاه مشکل را ارسال کنید.
  • این سیاست هیچ حق یا راه‌حل غیرقابل‌اسقاط قانونی مصرف‌کننده را محدود نمی‌کند.

نصب

ویندوز

  1. پکیج رسمی مشتری NikaToolFlow را Extract کنید.
  2. Adobe Premiere Pro را ببندید.
  3. فایل installer/install-windows.bat را اجرا کنید.
  4. در نصب اول برای آماده‌شدن Runtime اختیاری YouTube، اینترنت در دسترس باشد.
  5. پریمیر را باز کنید و از مسیر Window → Extensions → NikaToolFlow پنل را اجرا کنید.

macOS

  1. پکیج رسمی مشتری را Extract کنید و پریمیر را ببندید.
  2. installer/install-macos.command را اجرا کنید و در صورت نیاز اجازه اجرا را در تنظیمات امنیتی macOS بدهید.
  3. پریمیر را باز کنید و پنل را از مسیر Window → Extensions → NikaToolFlow اجرا کنید.

پکیج مشتری را فقط از لینک رسمی تحویل بگیرید. پکیج سورس فروشنده، Private Key امضا، تست‌های داخلی و ابزارهای فروشنده هرگز بخشی از دانلود معتبر مشتری نیستند.

پشتیبانی

برای سؤال‌های نصب، فعال‌سازی، خرید یا سازگاری با آدرس پشتیبانی تنظیم‌شده تماس بگیرید. نسخه دقیق NikaToolFlow، بیلد پریمیر، سیستم‌عامل و متن خطا را بنویسید.

Adobe و Premiere Pro علائم تجاری Adobe هستند. NikaToolFlow محصولی مستقل است و وابستگی یا تأیید رسمی از Adobe ندارد.
