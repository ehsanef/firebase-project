Questions, answered

Everything you need before installing.

Still need help? The support address can be configured in one line before launch.

Which Premiere versions are supported?
The CEP edition targets Premiere Pro 2020 through 2026. Because native commands can vary by build, OS, focus, and UI language, only exact combinations listed in the published test matrix should be treated as guaranteed.
How does the seven-day trial work?
Install the customer package, open NikaToolFlow from Window → Extensions, and select “Start 7-day trial.” Trial state remains on the workstation across Premiere restarts.
How is a paid license activated?
NikaToolFlow displays a Device ID. The seller issues a signed license for that workstation, and you paste it into the activation window. The current edition supports offline verification.
Does YouTube Grab bypass restrictions?
No. It is intended only for media you own, have permission to use, or are otherwise authorized to download. It does not bypass DRM or access controls.
What happens to imported clipboard images?
Smart Paste stores clipboard images and direct URL media in a durable NikaToolFlow folder instead of an operating-system temp folder, helping prevent offline media later.
Are experimental tools included?
Optional experimental tools are included but hidden by default. Some use Premiere’s unsupported QE DOM and should be tested on a duplicate project before production use.
